# Правила розробки та контрибуції (CONTRIBUTING)

Ласкаво просимо до проекту **Зелений Патруль (Green Patrol)**!  
Оскільки проект створюється командою для GENIUS Olympiad, ми дотримуємося чіткого і зрозумілого робочого процесу.

## 🌿 Гілки (Branches)

- Головна гілка `main` містить лише перевірений, стабільний код.
- Усі нові функції розробляються в окремих гілках (feature branches):
  ```bash
  git checkout -b feature/назва-фічі
  # наприклад: git checkout -b feature/wind-indicator
  ```

## 🔄 Pull Requests (PR)

1. Перед створенням PR переконайтеся, що всі тести проходять і код збирається:
   ```bash
   npm run lint
   npm run test
   npm run build
   ```
2. Створіть Pull Request у гілку `main`.
3. Опишіть коротко, які зміни внесено та як їх протестувати.

## 👁️ Обов'язкове код-рев'ю (Code Review)

- Для злиття (merge) у `main` потрібен **щонайменше 1 відгук (one review)** від другого учасника команди.
- Обидва автори повинні розуміти кожен рядок коду і вміти пояснити його журі на захисті.
