# 🌲 Зелений Патруль (Green Patrol) 🔥

**Зелений Патруль** — це навчально-просвітницька браузерна веб-гра та інтерактивний симулятор пожежної безпеки, розроблений для конкурсу **GENIUS Olympiad** (номінація *Coding*, тематика 2027 року: *екстремальна спека та лісові пожежі*).

Проект покликаний продемонструвати алгоритмічне мислення, навички моделювання природних процесів та принципи раціонального протипожежного планування. Гра працює повністю на стороні клієнта у браузері без бекенду, не потребує платних API та розгортається на **GitHub Pages**.

---

## 🎮 Ігрові режими

Гра натхненна циклом прийняття рішень *"Підготовка → Лихо → Результати"*:

1. **🛡️ Режим планування (Planning Mode)**:
   - **Фаза 1: «Підготовка»**: Гравець отримує обмежений бюджет балів (120–140) і створює план локалізації пожежі: прокладає мінералізовані протипожежні смуги (вартість 2 бали за клітинку) та встановлює дозорні вежі / гідранти (20 балів, зона захисту радіусом 8 клітинок зі зниженням імовірності загоряння на 60%).
   - **Фаза 2: «Пожежа»**: Симуляція запускається автоматично. Вогонь поширюється відповідно до заданих погодних умов (напрямок та швидкість вітру, вологість повітря, рельєф). Гравець спостерігає за поведінкою фронту вогню та може регулювати швидкість часу (1x, 2x, 5x).
   - **Фаза 3: «Результати»**: Система підраховує відсоток збереженого лісу, порівнює його з **об'єктивним базовим сценарієм (baseline)** (розрахунок на тому ж зерні випадковості за повної бездіяльності), показує витрачений бюджет і видає педагогічні рекомендації українською мовою.

2. **🧪 Режим пісочниці (Sandbox Mode)**:
   - Повна свобода експериментів: інтерактивне створення осередків вогню, прокладання смуг, висаджування лісу та створення водойм.
   - Динамічне налаштування погоди в реальному часі: повзунки швидкості вітру (0–25 м/с), компас напрямку вітру (0°–360°) та відносної вологості повітря (0%–100%).

## 🔬 Математична модель поширення вогню

Ядром симулятора є **стохастичний клітинний автомат (probabilistic cellular automaton)** на прямокутній сітці 100×100 з околом Мура (8 сусідніх клітинок).

### Стани клітинки:
- **0 (Unburned / Не згоріла)** — рослинність здорова та готова до загоряння при досягненні критичної температури.
- **1 (Burning / Горить)** — клітинка активно палає протягом фіксованої кількості тактів (`burnDuration = 3`), після чого вигорає.
- **2 (Burned / Згарище)** — вигоріла ділянка золи та попелу, яка більше не може загорітися.

### Мультиплікативна формула ймовірності загоряння:
Для кожної незгорілої клітинки $j$, що межує з палаючою клітинкою $i$, імовірність займання $p_{burn}$ обчислюється як добуток незалежних фізико-географічних факторів:

$$p_{burn} = p_{base} \times (1 + p_{veg}) \times (1 + p_{density}) \times p_{wind} \times p_{slope} \times \text{humidityFactor} \times \text{distanceWeight} \times \text{towerMitigation}$$

Де:
1. **$p_{base}$ (Базова ймовірність)**: базова ймовірність займання сусідньої клітинки за штилю, рівнинного рельєфу та нейтральної вологості ($p_{base} \approx 0.38$).
2. **$p_{veg}$ (Фактор рослинності)**: залежить від типу ландшафту (сосновий ліс: $+0.45$, трава: $+0.25$; вода, дороги та мінералізовані смуги мають від'ємне значення і **ніколи не горять**: $p_{burn} = 0$).
3. **$p_{density}$ (Густина біомаси)**: масштабування залежно від щільності горючих матеріалів.
4. **$p_{wind}$ (Вплив вітру)**: експоненційна модель за Александридісом (Alexandridis et al., 2008):
   $$p_{wind} = \exp(c_1 \cdot V) \cdot \exp(c_2 \cdot V \cdot (\cos(\theta) - 1))$$
   де $V$ — швидкість вітру, $\theta$ — кут між вектором вітру та вектором напрямку поширення полум'я. За вітром ($\theta = 0^\circ, \cos(\theta) = 1$) імовірність суттєво зростає; проти вітру ($\theta = 180^\circ$) — різко падає.
5. **$p_{slope}$ (Вплив схилу та висоти)**:
   $$p_{slope} = \exp(a_{slope} \cdot \text{slope})$$
   де $\text{slope} = \frac{\Delta h}{\text{distance}}$. Вогонь нагріває матеріали вище по схилу (конвекція та теплове випромінювання наближені до гілок), тому вгору пожежа рухається набагато швидше, ніж униз.
6. **$\text{humidityFactor}$ (Фактор вологості)**:
   $$\text{humidityFactor} = \max\left(0.01, 1 - \left(\frac{H}{100}\right)^{1.6} \times 0.98\right)$$
   При 100% вологості повітря ризик займання падає на 98%, різко придушуючи поширення.
7. **$\text{distanceWeight}$ (Геометрична відстань)**: прямі сусіди мають вагу $1.0$, а діагональні — $\frac{1}{\sqrt{2}} \approx 0.7071$ (оскільки відстань до них більша).
8. **$\text{towerMitigation}$**: зона дії спостережних веж та засобів швидкого реагування знижує ймовірність займання на 60% ($\times 0.4$).

## ⚠️ Чесні наукові обмеження моделі

- **Освітній характер**: Дана модель створена для інтерактивного навчання та наочної демонстрації факторів пожежної небезпеки учнями старших класів.
- **Не є оперативним інструментом**: Симулятор **не призначений** для оперативного прогнозування пожеж екстреними службами (ДСНС тощо).
- **Спрощення**: Параметри та константи є ілюстративними і збалансованими для стабільної та плавної симуляції у веб-браузері (100×100 клітинок), а не емпірично відкаліброваними під конкретні масиви лісу України.

## 📚 Референси та натхнення

У проекті використано теоретичні концепції, математичні структури та принципи геймдеву з таких джерел:

1. **Alexandridis et al. (2008) / Parallel_CellularAutomaton_Wildfire (Spetses Island 1990)**:
   - *Що взято*: мультиплікативна форма ймовірності займання, формула розрахунку вітрового фактора $p_w$ через косинус кута між вітром і вектором поширення, експоненційний коефіцієнт підйому на схил ($p_s$).
2. **Cell2Fire (Pais et al., arXiv:1905.09317)**:
   - *Що взято*: підхід до врахування вологості пального (fuel moisture), розрізнення типів рослинності та оцінка ефективності ізолюючих смуг у дискретних комірках.
3. **Almeida & Macau (2001/2011) / FireDynamicsAutomata**:
   - *Що взято*: класична трьохстанова модель клітинного автомата (Unburned → Burning → Burned) з фіксованим часом горіння кожної комірки. *(Примітка: репозиторій автора на GitHub наразі недоступний/приватний, тому принципи запозичено з опублікованих наукових статей авторів)*.
4. **PyTorchFire (Xia & Cheng)**:
   - *Що взято*: структура типізованих матриць ландшафту, висотної карти та нормалізація параметрів середовища.
5. **UNDRR "Stop Disasters!" (stopdisastersgame.org/game)**:
   - *Що взято*: виключно концепція геймдизайну: трифазний цикл *"Підготовка з обмеженим бюджетом → Симуляція лиха → Оцінка результатів та аналіз помилок"*. Жодного коду чи графіки не копіювалося.

## 🚀 Як запустити проект локально

Вимоги: встановлений **Node.js** (версія 18 або новіша) та **npm**.

1. **Встановлення залежностей**:
   ```bash
   npm install
   ```

2. **Запуск сервера розробки**:
   ```bash
   npm run dev
   ```
   Після запуску відкрийте у браузері посилання (зазвичай `http://localhost:3000` або `http://localhost:5173`).

3. **Запуск модульних тестів (Vitest)**:
   ```bash
   npm run test
   ```

4. **Перевірка лінтером та форматування**:
   ```bash
   npm run lint
   npm run format
   ```

5. **Збирання для продакшну / GitHub Pages**:
   ```bash
   npm run build
   npm run preview
   ```
   Зібраний статичний бандл генерується у папці `dist/`.
