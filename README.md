# 🌲 Зелений Патруль (Green Patrol) 🔥

**Зелений Патруль** — це навчально-просвітницька веб-гра та симулятор пожежної безпеки, розроблений для участі у конкурсі **GENIUS Olympiad** (номінація *Coding*, тематика 2027 року: *екстремальна спека та лісові пожежі*).

> **«Ти — фермер... Не дай своєму селищу згоріти!»**  
> Проект занурює гравця в роль фермера, який стикається зі стихійним лихом і повинен вчасно та стратегічно грамотно створити захисний периметр для порятунку свого рідного села.

Проект працює повністю на стороні клієнта у браузері без бекенду, не потребує платних API та розгортається на **GitHub Pages**.

## 🎮 Ігрові режими та нововведення

1. **🎬 Кінематографічне інтро:**
   - Гра розпочинається з чорного екрана, де з ефектом друкарської машинки з'являється звернення до гравця:
     *«Ти — фермер... Не дай своєму селищу згоріти!»*
   - Після цього екран плавно розсіюється у світле ігрове поле.

2. **🗺️ Тактичне поле 30×30 із функціональними клітинками:**
   - Замість дрібних одноманітних пікселів впроваджено сітку 30×30 з деталізованими об'єктами:
     - 🏡 **Хатинки селища фермера (`HOUSES`)**: головна мета оборони. Горючі споруди, захист яких визначає успіх місії!
     - 🌲 **Дерева / Ліс (`FOREST`)**: густі масиви, що горять інтенсивно.
     - 🌿 **Сухі кущі (`BUSHES`)**: легкозаймисті чагарники, через які вогонь мчить швидше за все.
     - 💧 **Водойма (`WATER`)**: озера та річки.
     - 🏖️ **Мокрий берег / зволожений пісок (`WET_GROUND`)**: насичена вологою прибережна смуга навколо води, на якій **вогонь не може горіти**.
     - 🚧 **Протипожежна смуга (`FIREBREAK`)**: мінералізований рів (коштує 2 бали).
     - 🗼 **Водонапірна вежа (`WATCHTOWER`)**: зональний захист (18 балів, знижує ризик загоряння на 65% у радіусі 6 клітинок).

3. **🧠 Глибока стратегія замість простого замуровування:**
   - **Температурна зона небезпеки (`heatDangerRadius = 2`)**: фермер фізично не може копати смуги впритул до палаючого осередку через небезпеку опіків та їдкий дим. Це унеможливлює «закриття вогню в коробку на старті» і змушує планувати справжні оборонні рубежі заздалегідь!
   - **Захист вологих берегів**: річки та ставки тепер мають широку зону зволоження, яку можна вигідно інтегрувати у свою лінію оборони.

4. **🏃 Режим виживання (Інтерактивна історія «Хата, поле і вогонь»):**
   - Новий сюжетний режим текстового квесту та прийняття рішень для виживання у безпосередній зоні пожежі.
   - **Управління у стилі split-screen**: вибір [А] або [Б] можна робити кліком по кнопках, натисканням клавіш **A** чи **B**, або **кліком по лівій/правій половині екрана**.
   - **Початок історії**: «Ти — фермер, тобі пора вставати...» (перехід за кліком по екрану).
   - **5 життєвих правил безпеки на фініші**:
     1. *Ніякої синтетики:* Одяг із синтетики миттєво плавиться на шкірі під дією жару.
     2. *Падай на карачки:* Гарячий чадний газ підіймається вгору, знизу біля підлоги залишається придатне для дихання повітря.
     3. *Не біжи за вітром:* Вогонь біжить за вітром швидше за людину — тікати треба виключно перпендикулярно.
     4. *Не лізь на гору від вогню:* Висхідні потоки гарячого повітря прискорюють полум'я на схилі пагорба.
     5. *Ховайся там, де нічому горіти:* Зелені соковиті кущі спалахують від жару за секунди; рятує тільки гола рілля або каміння.

## 🔬 Математична модель поширення вогню

Ядром симулятора є **стохастичний клітинний автомат (probabilistic cellular automaton)** на прямокутній сітці 30×30 з околом Мура (8 сусідніх клітинок).

### Мультиплікативна формула ймовірності займання:
Для кожної незгорілої клітинки $j$, що межує з палаючою клітинкою $i$, імовірність займання $p_{burn}$ обчислюється як:

$$p_{burn} = p_{base} \times (1 + p_{veg}) \times (1 + p_{density}) \times p_{wind} \times p_{slope} \times \text{humidityFactor} \times \text{distanceWeight} \times \text{towerMitigation}$$

Де:
1. **$p_{base} \approx 0.38$** — базова ймовірність загоряння за нейтральних умов.
2. **$p_{veg}$**:
   - `BUSHES`: $+0.60$ (кущі займаються найшвидше).
   - `HOUSES`: $+0.55$ (дерев'яні хатинки горять інтенсивно).
   - `FOREST`: $+0.45$.
   - `GRASS`: $+0.25$.
   - `WATER`, `ROAD`, `FIREBREAK`, `WET_GROUND`: $-1.0$ (**ніколи не горять**, $p_{burn} = 0$).
3. **$p_{wind}$**: експоненційна модель за Александридісом (Alexandridis et al., 2008):
   $$p_{wind} = \exp(c_1 \cdot V) \cdot \exp(c_2 \cdot V \cdot (\cos(\theta) - 1))$$
4. **$p_{slope}$**: прискорення руху полум'я вгору схилом:
   $$p_{slope} = \exp(a_{slope} \cdot \text{slope})$$
5. **$\text{humidityFactor}$**: при 100% вологості повітря ризик займання пригнічується на 98%.
6. **$\text{towerMitigation}$**: вежі зменшують ризик загоряння в радіусі дії на 65% ($\times 0.35$).

## 📚 Референси та натхнення

1. **Alexandridis et al. (2008) / Parallel_CellularAutomaton_Wildfire (Spetses Island 1990)**: мультиплікативна форма ймовірності займання, формула вітрового фактора $p_w$ та експоненційний коефіцієнт підйому на схил ($p_s$).
2. **Cell2Fire (Pais et al., arXiv:1905.09317)**: класифікація типів горючих матеріалів (fuel types: ліс, сухі кущі, будівлі) та вплив вологості на швидкість просування фронту пожежі.
3. **Almeida & Macau (2001/2011)**: трифазна дискретна модель станів (Unburned → Burning → Burned) із кінцевою тривалістю фази горіння.
4. **PyTorchFire (Xia & Cheng)**: нормалізація матриць рельєфу та параметрів навколишнього середовища на типізованих масивах.
5. **UNDRR "Stop Disasters!"**: ігровий цикл «Підготовка фермера (бюджет) → Пожежа → Оцінка збереження селища та лісу».

## 📁 Структура проекту

```
Green_Patrol/
├── .github/workflows/
│   ├── ci.yml            # Автоматичний запуск тестів і збирання на PR / push
│   └── deploy.yml        # Автодеплой на GitHub Pages
├── src/
│   ├── simulation/       # Чиста математична логіка без DOM-залежностей
│   │   ├── types.ts      # Типи станів, ландшафтів (вкл. HOUSES, BUSHES, WET_GROUND)
│   │   ├── config.ts     # Конфігурація фізичних коефіцієнтів та heatDangerRadius
│   │   ├── rng.ts        # Детермінований PRNG (mulberry32)
│   │   ├── grid.ts       # Сітка 30x30 на TypedArrays та розрахунок вологих берегів
│   │   ├── step.ts       # Алгоритм кроку клітинного автомата
│   │   ├── baseline.ts   # Розрахунок детермінованого базового сценарію
│   │   └── planning.ts   # Менеджер ресурсів фермера та перевірка зон небезпеки
│   ├── ui/               # Візуалізація та інтерфейс користувача
│   │   ├── renderer.ts   # Рендерер Canvas 2D (детальні спрайти будинків, дерев, вогню)
│   │   ├── app.ts        # Контролер гри, кінематографічне інтро, моніторинг селища
│   │   └── style.css     # Стилі темної теми, анімація друкарської машинки
│   ├── content/
│   │   └── scenarios.ts  # 3 карти-головоломки (Річковий бір, Степовий хутір, Пагорб)
│   └── main.ts           # Точка входу веб-додатка
├── tests/
│   └── simulation.test.ts # 9 модульних тестів (Vitest)
├── index.html            # Головна розмітка (інтро, легенда, панелі)
├── package.json          # Залежності та скрипти проекту
└── README.md
```

## 🚀 Як запустити проект локально

```bash
# 1. Встановити залежності
npm install

# 2. Запустити локальний сервер розробки
npm run dev

# 3. Запустити тести Vitest (9 тестів)
npm run test

# 4. Перевірка лінтером та збирання для продакшну
npm run lint
npm run build
```
